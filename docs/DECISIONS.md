# 设计决策记录

每条写四样：选了什么、放弃了什么、为什么、什么时候会改。面试时讲「技术选型的取舍」就从这里取。

被后来的决定取代的条目不删除，标注「已被 D00X 取代」。能说清自己为什么改主意，本身就是加分项。

## D001 用 Python，只借 OpenClaw 的架构思想（2026-10-07）
- 选择：Python 自己搭。
- 放弃：直接改 OpenClaw 的 TypeScript 源码。
- 理由：目标岗位以 Python 为主；OpenClaw 约 43 万行，读不完。
- 何时重新考虑：目标岗位明确要求 TypeScript。

## D002 以 minimal-harness 为底座（2026-10-07）已被 D005 取代
- 当时的理由：已有一个最小循环，可以直接加模块。

## D003 存储用 SQLite + Markdown（2026-10-07）已被 D006 取代
- 当时的理由：零配置，单机够用。

## D004 场景定为求职（2026-10-07）
- 选择：盯岗位、公司调研、面试准备、进度跟进。
- 放弃：通用个人助理。
- 理由：自己天天用，有真实数据；正好覆盖长程智能体的四个特征。
- 何时重新考虑：不会。

## D005 项目建在 fastapi-scaffold 上，做成部署上线的网页应用（2026-10-07）
- 选择：后端沿用自己的 fastapi-scaffold，加 React 前端，部署到云服务器。智能体循环在 `app/agent/` 里重写。
- 放弃：本地命令行工具；以 minimal-harness 为底座。
- 理由：目标从「吃透智能体」扩大为「走通一次全栈开发并掌握智能体」。脚手架已经具备接口、数据库、队列、后台任务、容器编排，缺的正是一个真实业务。长程智能体恰好需要后台任务和持久状态，两者是互相成全的。
- 代价：范围变大，要学的东西变多。用「先上线空壳再加功能」的顺序来控制风险。
- 何时重新考虑：不会。计划从这一条起冻结。

## D006 任务状态和记忆放 PostgreSQL（2026-10-07）
- 选择：goals、tasks、steps、approvals、audit_logs、memories 都放 PostgreSQL。
- 放弃：SQLite；用 Markdown 文件存记忆。
- 理由：脚手架已有 PostgreSQL；接口进程和 worker 进程要同时读写，SQLite 不合适；网页应用里用户通过页面编辑记忆，比改文件自然。
- 保留的思想：记忆对用户可见、可改。
- 何时重新考虑：记忆超过几百条时再考虑向量检索。

## D007 前端用 React + TypeScript + Vite + Tailwind（2026-10-07）
- 选择：单页应用，打包成静态文件。
- 放弃：Next.js（多一个要部署的服务端）；Streamlit 或 Gradio（不算前端开发经验）；纯 HTML。
- 理由：岗位需求最多，AI 写得最熟，部署只是拷贝一个文件夹。
- 何时重新考虑：需要服务端渲染或搜索引擎收录时。

## D008 一台服务器 + Docker Compose + Caddy（2026-10-07）
- 选择：单机部署；Caddy 装在服务器上做反向代理并自动配置 HTTPS；Compose 用脚手架的生产配置。
- 放弃：Kubernetes；平台即服务；脚手架文档里的系统 Nginx 加手动证书。
- 理由：单用户项目一台机器足够；Compose 本地和线上同一套；Caddy 的证书全自动，配置几行。
- 待定：服务器买在哪个地区，阶段 1 决定并记录。
- 何时重新考虑：要多台机器或自动扩缩容时。

## D009 通知先用邮件（2026-10-07）
- 选择：沿用脚手架的邮件能力，加网页内的未读提示。
- 放弃：Telegram、飞书机器人。
- 理由：不依赖任何聊天平台，在哪都能用；脚手架已有。
- 何时重新考虑：想要手机即时推送时加一个渠道。

## D010 每个阶段先建立判断标准，再让 AI 写代码（2026-10-07）
- 选择：每个阶段动手前先看少量指定的外部资料，写下自己的标准，做完后用标准审查 AI 的产出。资料清单在 `docs/RESOURCES.md`，标准在 `coach/standards/`。
- 放弃：直接让 AI 做完再去理解；系统地把每门技术学完再动手。
- 理由：以前让 AI 直接做，东西能用，但自己判断不了好坏。只学不做又推进不下去。折中是每个主题限时看几节实操者写的资料，产出是可以拿来检查代码的标准。
- 代价：每个阶段多花 2 到 3 小时。
- 这不是改方向：路线、选型、功能都没变，只是每个阶段前面加了一步。
- 何时重新考虑：某个钩子连续两次超时一倍以上时，砍掉它的选看资料。
