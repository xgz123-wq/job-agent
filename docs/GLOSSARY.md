# 术语对照

读英文资料时对着查。遇到新词让教练加进来。

| 英文 | 中文 | 一句话解释 |
| --- | --- | --- |
| agent | 智能体 | 能自己决定下一步、能调用工具的程序 |
| agent loop | 智能体循环 | 模型想、调工具、看结果、再想，直到完成 |
| harness | 运行框架 | 包在模型外面、负责循环和工具调用的那层代码 |
| gateway | 网关 | 常驻的总机进程，所有消息都经过它 |
| channel | 渠道 | 聊天入口，如 Telegram、飞书 |
| heartbeat | 心跳 | 定时唤醒智能体的机制 |
| cron | 定时任务 | 按固定时间表触发的任务 |
| daemon | 守护进程 | 一直在后台运行的程序 |
| tool call | 工具调用 | 模型请求执行某个工具 |
| skill | 技能 | 用 Markdown 写给模型看的操作手册 |
| connector | 连接器 | 对接某个第三方服务的工具 |
| context window | 上下文窗口 | 模型一次能看到的全部文字 |
| compaction | 压缩 | 上下文快满时把旧内容总结变短 |
| session | 会话 | 一段连续的对话及其历史 |
| state machine | 状态机 | 规定任务有哪些状态、怎么从一个变到另一个 |
| checkpoint | 存档点 | 存下当前进度，之后可以从这里继续 |
| idempotent | 幂等 | 同一个操作做两次和做一次效果一样 |
| human in the loop | 人在回路 | 关键动作要人确认 |
| approval | 审批 | 批准或拒绝一个动作 |
| sandbox | 沙箱 | 把程序关在隔离环境里运行 |
| VM | 虚拟机 | 用软件模拟出来的一台电脑 |
| prompt injection | 提示词注入 | 外部内容里藏指令，骗模型去做事 |
| untrusted content | 不可信内容 | 来自网页、邮件等外部来源的文字 |
| egress | 出网流量 | 从系统里发往外部网络的请求 |
| least privilege | 最小权限 | 只给完成任务所需的最少权限 |
| credential | 凭证 | 密码、令牌、API key 的统称 |
| eval | 评测 | 用固定任务集给系统打分 |
| trajectory | 轨迹 | 一次任务从头到尾的全部步骤记录 |
| subagent | 子智能体 | 被主智能体派去做子任务的智能体 |
| frontend / backend | 前端 / 后端 | 用户看到的页面 / 页面背后处理请求的程序 |
| API | 接口 | 程序之间约定好的沟通方式 |
| endpoint | 接口地址 | 一个具体的接口，如 `POST /goals` |
| schema | 数据格式定义 | 规定请求或响应里有哪些字段 |
| ORM | 对象关系映射 | 用代码里的类来读写数据库表 |
| migration | 迁移 | 一次数据库结构变更的记录 |
| JWT | 令牌 | 登录后发的身份凭证，每次请求带上 |
| CORS | 跨域 | 浏览器限制一个网站的页面去请求另一个网站的接口 |
| cache | 缓存 | 把算过的结果暂存起来，下次直接用 |
| message queue | 消息队列 | 一边放任务、一边取任务的传送带 |
| broker | 中间人 | 队列所在的地方，本项目里是 Redis |
| worker | 工作进程 | 从队列里取任务来执行的后台程序 |
| SSE | 服务器推送事件 | 服务器持续往浏览器单向推送消息 |
| container | 容器 | 把程序和它的运行环境打包在一起的隔离单元 |
| image | 镜像 | 容器的模板，容器是它运行起来的样子 |
| reverse proxy | 反向代理 | 站在服务器门口接请求，再转给后面真正处理的程序 |
| DNS | 域名解析 | 把域名翻译成服务器的数字地址 |
| CI / CD | 持续集成 / 持续部署 | 推送代码后自动检查测试 / 自动上线 |
| PR | 合并请求 | 请求把一个分支的改动合进主分支，并留下讨论记录 |
| lint | 静态检查 | 不运行代码，只看写法有没有问题 |
