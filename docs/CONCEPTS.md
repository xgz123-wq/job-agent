# 概念卡

每样技术只学到 20%：能回答卡上的三个问题就够，不往下挖。第一次用到时让教练带着看一遍真实文件。

学的方式不止一种。「去哪学」一栏写的是 `docs/RESOURCES.md` 里的资料编号，有文章也有视频；没写的由教练对着仓库里的真实文件讲。

## 每张卡的三个问题

学到 20% 的标准，对任何一张卡都一样：

1. 它是什么？用一句自己的话说。
2. 在这个项目里，没有它会怎样？
3. 它出问题了，我去哪看？（哪个文件、哪条命令、哪个日志）
