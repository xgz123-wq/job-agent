# 卡点反馈模板

卡住时，把下面三项填好发给 Claude Code（口语就行，不用写得完整），或者直接说「卡住了」，它会按这三项问你。

```
我想做的事：
实际发生了什么（报错原文、或者哪句话没看懂）：
我已经试过的：
```

可以再加一句你自己的判断，帮它更快对症：

- 环境问题：装不上、跑不起来、报错看不懂
- 概念问题：不明白这个东西为什么存在
- 设计问题：不知道该怎么选
- 代码问题：看不懂它写的代码

## 教练会怎么处理

| 类型 | 处理方式 |
| --- | --- |
| 环境 | 它直接修，你不用排查 |
| 概念 | 先给类比，再带你看参考项目里的真实代码 |
| 设计 | 给两三个选项和代价，你来选 |
| 代码 | 它把代码改短、拆开，直到你能逐行讲 |

## 卡点记录

值得记的卡点写在这里。面试被问「遇到过什么困难」时，从这里找素材。

格式：

```
### 日期 一句话标题
- 现象：
- 原因：
- 怎么解决的：
- 学到了什么：
```
